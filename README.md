# charlexdew

Personal landing page and blog for **charlexdew**.

Built with [Astro](https://astro.build/) and deployed to GitHub Pages.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

## Deployment

Push to `main`. GitHub Actions builds the site and deploys it to GitHub Pages.

Expected URL:

https://charlexdew.github.io/
